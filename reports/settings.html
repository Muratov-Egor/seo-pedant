Как применить изменения. Страница ничего не пишет на диск — она статическая. Скопируйте JSON ниже в config/pages.json и закоммитьте.
• Отключить страницу (переключатель «В прогоне») безопаснее, чем удалять: история находок по ней сохраняется.
• Переименование slug обнуляет историю проблем по странице — slug лучше не менять.
• Для новой страницы после коммита нужен сбор: node lib/collect.mjs --slug <slug> (или полный npm run audit).
